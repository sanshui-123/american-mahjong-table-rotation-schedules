## 2. Host Pacing & Table Night Notes

- **Round clock:** 45–55 minutes per round (typically 3–4 games per round) keeps a 4-round club night comfortably within 3.5–4 hours including breaks.
- **Seat swaps:** Assign fixed starting player numbers (`Player 1` … `Player N`) at check-in so guests can immediately find their next table and wind seat between rounds.
